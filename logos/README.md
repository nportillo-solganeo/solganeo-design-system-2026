| Version | Fond | SVG | PNG | PNG HD |
| --- | --- | --- | --- | --- |
| Horizontal | Clair | `svg/Logo_Solganeo-Light.svg` | `png/Logo_Solganeo-Light.png` | `png-hd/Logo_Solganeo-Light@HD.png` (2912 px) |
| Horizontal | Foncé | `svg/Logo_Solganeo-Dark.svg` | `png/Logo_Solganeo-Dark.png` | `png-hd/Logo_Solganeo-Dark@HD.png` (2912 px) |
| Vertical | Clair | `svg/Logo_Solganeo_vertical-Light.svg` | `png/Logo_Solganeo_vertical-Light.png` | `png-hd/Logo_Solganeo_vertical-Light@HD.png` (1760 px) |
| Vertical | Foncé | `svg/Logo_Solganeo_vertical-Dark.svg` | `png/Logo_Solganeo_vertical-Dark.png` | `png-hd/Logo_Solganeo_vertical-Dark@HD.png` (1760 px) |
| Symbole seul | Clair ou foncé | `svg/Logo_Solganeo.svg` | `png/Logo_Solganeo.png` | `png-hd/Logo_Solganeo@HD.png` (1584 px) |

- `svg/` : les fichiers vectoriels d'origine. Le symbole et les versions verticales contiennent une petite image intégrée pour le rond central : certains outils qui « nettoient » les SVG la retirent. Si le rond disparaît, utilise le PNG HD.
- `png/` : les PNG d'origine, petite taille.
- `png-hd/` : exports haute résolution des SVG d'origine, fond transparent, pour les slides, les documents et l'email.

Les couleurs sont figées dans les fichiers : choisis la version selon le fond, ne recolore pas, ne déforme pas.
