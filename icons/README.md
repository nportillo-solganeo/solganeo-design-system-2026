# Icônes

Icônes Material Symbols de Google, style Rounded, graisse 300, fichiers SVG d'origine (licence Apache 2.0). Grille 960 × 960, `viewBox="0 -960 960 960"`, un seul tracé plein par icône.

Familles :

- Navigation : arrow_forward, arrow_back, arrow_outward, chevron_right, chevron_left, keyboard_arrow_down, menu, close, search, home, open_in_new, language
- Actions : add, remove, check, check_circle, download, upload, share, edit, delete, refresh, filter_list, more_horiz, progress_activity
- Contact : mail, call, calendar_month, schedule, location_on, chat, forum, send, videocam
- Statut : info, warning, error, help, lock, verified_user, notifications
- Métier : handshake, groups, person, badge, work, apartment, trending_up, analytics, monitoring, bar_chart, query_stats, campaign, ads_click, rocket_launch, lightbulb, stars, psychology, smart_toy
- Tech : database, cloud, cloud_sync, hub, code, api, settings, tune, dashboard, school, workspace_premium

Les fichiers n'ont pas de couleur : affichés avec `<img>`, ils sont noirs. Pour qu'une icône prenne la couleur du texte (`ink`, `accent`…) ou soit animée, utilise le composant `Icon` ou colle le SVG en ligne avec `fill="currentColor"`. Une icône absente de la liste se prend sur fonts.google.com/icons avec les mêmes réglages (Rounded, Weight 300, Fill 0, Grade 0, Optical size 24), puis s'ajoute dans `icons/svg/` et dans `components/src/components.jsx` (objet `ICONS`).
