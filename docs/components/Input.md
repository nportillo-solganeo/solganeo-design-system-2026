# Input

Champ de formulaire avec label, aide et erreur ; textarea avec `multiline`.

Le consommateur fournit `label` et, selon le cas, `required`, `help`, `error`, `placeholder`, `value`/`onChange` ou `defaultValue`, `type`. Bordure `line-strong` (3:1), focus `focus`, erreur `danger` avec un message texte. Texte à 16px pour éviter le zoom sur mobile.
