# NavBar

Barre de navigation sticky de 76px : logo, liens, CTA primaire.

Le consommateur fournit `logo` (`{ light, dark }` : URLs des logos `Logo_Solganeo-Light` et `-Dark`, la bonne version s'affiche selon le thème), `links`, `active` (lien courant, souligné en `signal`), `cta` et `onCta`. Sans `logo`, le nom s'affiche en texte.
